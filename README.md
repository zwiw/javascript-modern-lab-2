
# javascript-modern-lab-2

Lucrare de laborator nr. 2 – JavaScript modern.

## Structură

- `task-01/` – filter(), map(), reduce() pe un array de note
- `task-02/` – module `utils.js`, `students.js`, `main.js`
- `task-03/` – coș de cumpărături
- `task-04/` – gestionarea angajaților (studiu individual nr. 1)

## Rulare

Necesită Node.js. Din rădăcina proiectului:

```bash
node task-01/main.js
node task-02/main.js
node task-03/main.js
node task-04/main.js
```
